Customer Churn Analysis

Personal project

Built a Python pipeline on a synthetic 3,000-customer dataset: Pandas/NumPy cleaning, an SQL query for churn by plan, and EDA plots. Compared Logistic Regression and Random Forest with 5-fold cross-validation; Logistic Regression scored a test ROC-AUC of 0.71 and was the better model. Finding: basic-plan customers churn the most (18.5% vs ~12.5% on other plans).
